# Member score v6.33

One data correction: each state's partisan lean (`app/data/state_pvi.json`)
now uses Cook's own weighting of the two presidential elections.

## What was wrong

`scripts/fetch_state_pvi.py` computes each state's Cook PVI from official
returns: the state's two-party Democratic share minus the nation's, over
2020 and 2024. It averaged the two elections equally. Cook has weighted the
more recent election more heavily since its 2022 release, and the generator
said so in a comment, calling the weights undisclosed and declining to
replicate them.

The weights can be measured. Compared with Cook's published 2025 state
PVIs, as printed in the state table of the Wikipedia revision pinned in
`app/data/district_pvi_sources.json`, using the generator's own pinned
returns (2026-10-08):

| 2024 weight | jurisdictions off Cook's published value |
|---|---|
| 0.50 (as shipped) | 18 of 51, each by one point |
| 0.60 | 14 |
| 0.70 | 4 |
| **0.75** | **0** |
| 0.80 | 4 |

At 75/25 the figures are Cook's, all 51 of them. The site labels the
number "Cook PVI", and the House district figures beside it were already
Cook's published values, so the equal-weight states were the outliers.

## What changes

The 18 jurisdictions each move one point toward Cook's figure:

- AK, AR, IN, KS, NC, ND, NE, OH, OK, UT, WI and WY move one point less
  Republican (Wisconsin to EVEN).
- ME, MN, OR, WA and DC move one point more Democratic; NJ one point less.

The state PVI is a senator's seat lean (`_seat_pvi`) in Constituent
Alignment: the expected break rate for a seat of that lean (fitted every
run, `constituent_reference.json`), the seat-conditional position
congruence, and the approval part's own-lean term (v6.29). Senators from
those 18 states are read on the corrected lean, and the per-run fits are
refitted from the corrected inputs. House seats read the district table,
which was already Cook's, so nothing changes for representatives.

The generator's test now checks Cook's published values exactly, where it
allowed one point either way.
